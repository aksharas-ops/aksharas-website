# Aksharas Website – V48 Branch Photo Update

This package is based on V47 and updates only the three branch-card photographs.

- Porur: updated enhanced exterior photograph (`assets/branch-porur.webp`)
- Perumbakkam: enhanced branch-front photograph (`assets/branch-perumbakkam.webp`)
- Madipakkam: enhanced branch-front photograph (`assets/branch-madipakkam.webp`)

The branch card layout, CSS, image aspect ratios, text, links, contact details, and all other website sections are unchanged. Branch images are stored in WebP format for smaller file sizes and faster loading.

Deploy by uploading the contents of the `aksharas_v43` folder to the existing website repository root and committing to `main`. Do not upload the ZIP file itself.
